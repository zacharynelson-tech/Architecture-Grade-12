Cycle 1 - Building Codes I - Purpose, Occupancy, Height & Area

Every commercial building starts with the rules that decide what it can be, how big it can get, and who it serves.

12.1.112.1.212.1.312.3.112.9

Learning Objectives

Understand

Explain the purpose of building codes (health, safety, welfare) and name the codes an architect references throughout design.

Apply

Identify the occupancy classification of a building and apply height and area limits, including mixed-use occupancies, to a project.

Create

Create a code summary sheet for a commercial building and a first Revit schematic set: plans, elevations, and a section.

Big Ideas & Essential Questions

▸
12.1 - Building Codes
Big Idea(s)
  • It is essential for an Architect to be able to read and understand how building codes are applied.
  • Early integration of building codes into the design process benefits the design.
Essential Question(s)
  • What is the purpose of building codes?
  • Why are there different building codes required for different building types?
  • How do you read and apply building codes for your design?
12.3 - Building Information Modeling for Commercial Architecture
Big Idea(s)
  • BIM promotes collaboration between all stakeholders of a project to improve project efficiency and delivery.
  • BIM enhances the capabilities of architects by providing them with powerful tools for design exploration, collaboration, data analysis, and project management.
Essential Question(s)
  • How can BIM be beneficial over traditional CAD?
  • What are the best practices for creating a comprehensive and accurate BIM model?

Lesson Outline

▸
  • Course Kickoff - The Commercial Shift
    How Grade 12 differs from residential work in Grade 11. Walk through the year's ten cycles, the two DSAs, and how each cycle's tags map to the exam.
  • Why We Have Codes
    Purpose of codes: health, safety, welfare. State Building Code vs. the International Code Council (ICC) I-Codes. How architects find code information, including the State of CT Building Code.
  • Use & Occupancy Classifications
    The occupancy groups: Assembly, Business, Education, Factory and Industrial, High Hazard, Institutional, Mercantile, Residential, Storage, and Utility and Miscellaneous. Classify real buildings.
  • Height & Area Limits
    Factors that limit building height and area. How mixed-use buildings with different occupancy types are classified. Calculate height and area maximums for a given project.
  • Revit Studio Day
    Revit user interface and new file setup. Basic modeling: walls and floors.
  • Revit Studio Day (cont.)
    Roofs, plan/elevation/section views, and checking your model against your code summary.
  • Wrap-Up
    Finish your code summary sheet and Revit schematic set. Review for the cycle.

This is a rough outline and is subject to change.

Independent Assignments

Reading + Guided Notes

Building Codes and Occupancy Classification
▸

Read the overview of building codes and the occupancy classification section, then complete the guided reading notes: purpose of codes, the companion I-Codes, how occupancy and construction type limit height and area, and what a fire wall does.

Source/materials: Building Construction Illustrated, Section 2.05 Building Codes (PDF p. 53) and Section 2.07 Occupancy Classification (PDF p. 55). Supplemental reading from the ICC I-Codes / State of CT Building Code: source TBD.

LevelDescription
BeginningGuided notes largely incomplete or inaccurate; occupancy groups not distinguished.
DevelopingMostly complete; some answers copied or vague about how occupancy affects height and area.
ProficientFully complete and accurate, in your own words; explains purpose of codes and how occupancy drives limits.
ExemplaryAll Proficient criteria met, plus a follow-up question about how a specific building you know would be classified.

Reflection Check-In

Formative - complete after Reading & Guided Notes
▸

Formative: not scored on the rubric scale. A checkpoint before moving into hands-on work. Write a few sentences for each prompt.

  • Which occupancy group does the building you spend the most time in belong to, and what do you think that classification requires of it?
  • Why might checking the code early in design benefit a project more than checking it at the end?

Software Exercise - Revit Fundamentals

Interface, new file setup, and basic modeling
▸

Set up a new Revit project and model a small one-story commercial building from a provided plan using walls, floors, and a roof. Generate a floor plan, two elevations, and one building section.

Source/materials: Revit practice file / provided plan (teacher-provided)

LevelDescription
BeginningSetup incomplete, or walls/floors/roof missing or misplaced.
DevelopingModel mostly complete but with placement or level errors; views incomplete.
ProficientSetup correct, model matches the provided plan, and plan, elevations, and section are generated.
ExemplaryAll Proficient criteria met, plus clean organization (named levels, correct wall types) ready to build on.

Precedent Analysis

Research a real commercial building
▸

Choose one real, built commercial building with a single clear occupancy type. In one page, identify its occupancy group, describe its historical and site context, and explain how its design responds to its use.

Source/materials: Student-selected sources, 2+ required

LevelDescription
BeginningSummary thin or inaccurate; occupancy group missing or incorrect.
DevelopingOccupancy group correct; context or design response is shallow.
ProficientAccurate, well-sourced, and clearly connects the building's design to its occupancy and site.
ExemplaryAll Proficient criteria met, plus a clear idea from the precedent you could use in your own work.
